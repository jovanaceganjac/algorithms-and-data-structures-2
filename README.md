# Algorithms and Data Structures 2

Homework assignments for *Algorithms and Data Structures 2* at ETF Belgrade.

- **Search trees** (`asp2dom1`) — ternary search over a sorted matrix and an
  **AVL tree** with rotations (C)
- **Hashing** (`asp2dom3`) — hash table with a pluggable address function,
  an **adaptive hash table** and **bidirectional hashing** (C++, CMake)
